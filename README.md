# Novi Future Finance – website starter

Deze zelfstandige website is opgebouwd als statische HTML/CSS/JavaScript-site en is bedoeld als eerste versie voor GitHub Pages.

## Bestanden
- `index.html` – homepage
- `diensten.html`, `beleggen.html`, `hypotheken.html`, `tarieven.html`
- `over-ons.html`, `duurzaamheid.html`, `contact.html`, `intranet.html`
- `styles.css` – vormgeving
- `script.js` – mobiel navigatiemenu

## Publiceren met GitHub Pages
1. Maak in GitHub een repository aan (bijvoorbeeld `novi-future-finance`).
2. Upload alle bestanden en behoud de mappenstructuur.
3. Open **Settings → Pages**.
4. Kies **Deploy from a branch**, selecteer `main` en `/ (root)`, en sla op.
5. Wacht tot GitHub Pages de website publiceert.

## Nog te doen vóór publicatie
- Download het logo en sla het lokaal op in `assets/`; vervang daarna de externe logo-URL in de HTML door `assets/logo.png`.
- Voeg de originele foto's en teamfoto's toe.
- Vul zakelijke contactgegevens in.
- Koppel het contactformulier aan een echte formulierdienst/backend.
- Voeg de ontbrekende intranetbestanden toe.
- Richt voor het intranet echte toegangsbeveiliging in. Zet vertrouwelijke documenten niet op een openbare GitHub Pages-site.
- Controleer alle teksten en financiële claims inhoudelijk voordat de site live gaat.

## Belangrijk
GitHub Pages is statische hosting. Er zit geen server, database of gebruikersauthenticatie in deze website.
